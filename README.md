SQL Window Functions
Project Overview
This project demonstrates the use of SQL Window Functions to perform ranking, sequential analysis, and salary aggregation using an employee dataset.
Objective
The objective of this project is to practice and understand SQL Window Functions and apply them to employee salary and department-level analysis.

Analysis Performed
Sorted employees based on salary.
Ranked employees according to salary.
Compared RANK(), DENSE_RANK(), and ROW_NUMBER().
Generated department-wise salary rankings.
Calculated total salary using Window Functions.
Performed department-level salary analysis.
Compared current salary with previous and subsequent employee salaries using LAG() and LEAD().
Key Learning
Through this project, I gained practical experience in using SQL Window Functions for ranking, aggregation, and sequential data analysis.
